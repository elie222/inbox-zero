# Dependency patches

`@inbox-zero__emulate@0.12.0.patch` adds development-emulator behavior used by mailbox sync and browser tests: Microsoft folder delta routes with expired-cursor responses, persisted message flags and inbox classification, raw attachment bytes, category color updates, and the full Outlook color set. Delta links use `graph.microsoft.com`; the Outlook client rewrites those requests to the local emulator. The Google patch supports negative mailbox scopes (`-in:`), multipart media uploads and resumable uploads for drafts, and keeps each attachment's `X-Attachment-Id` part header. The Microsoft patch also adds inline draft attachments, attachment deletion, upload-session cancellation, a `Location` header on completed attachment uploads, and correct reassembly of uploads whose chunks aren't multiples of three bytes. Version 0.12.0 already includes RS256 identity tokens/JWKS, Gmail mailbox profiles, and literal/Boolean Graph search, so those fixes are no longer patched. Application identity-token verification remains enabled.

Remove each remaining patch section once the published emulator includes equivalent behavior. Verify installed-package search with `pnpm test __tests__/emulator/google-mail-query.test.ts __tests__/emulator/microsoft-mail-query.test.ts`. Validate provider compatibility with `RUN_INTEGRATION_TESTS=true pnpm --dir apps/web exec vitest run __tests__/integration/google-emulator-oauth.test.ts __tests__/integration/outlook-mailbox-delta.test.ts __tests__/integration/outlook-mailbox-flag.test.ts __tests__/integration/outlook-inbox-classification.test.ts __tests__/integration/outlook-attachment-stream.test.ts __tests__/integration/outlook-category-update.test.ts __tests__/integration/outlook-mail-view-parity.test.ts __tests__/integration/draft-attachments.test.ts` and the emulated Playwright login flow.

The optional `createEmulator({ hostname })` argument makes native integration provider listeners bind explicitly to loopback. The native fixture launcher uses the package's `reset()` API through a separate loopback control listener. Remove this API patch once the published package supports binding a hostname, and validate the native integration runner.

`@sqlite.org__sqlite-wasm@3.53.4-build1.patch` aligns the legacy worker's proxy construction with the primary initializer's static proxy asset URL. Turbopack otherwise treats its dynamic URL as a worker module dependency and fails compilation even when only the package's default SQLite initializer is used. Mail search uses SAHPool; the legacy proxy is not instantiated by the application. Remove after upgrading to a release with the same bundler-compatible legacy worker implementation, and validate with the emulated local search browser suite.

`@better-auth__oauth-provider@1.7.4.patch` accepts host-bearing native redirect URIs such as Cursor's `cursor://anysphere.cursor-mcp/oauth/callback`. Better Auth 1.7.4 only allows authority-free reverse-domain schemes (`com.example.app:/callback`). Remove after upgrading to a release that includes https://github.com/better-auth/better-auth/pull/10956, and validate with `pnpm test utils/mcp/oauth-flow.test.ts`.
