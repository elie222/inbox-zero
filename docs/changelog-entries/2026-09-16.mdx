---
description: "Slash Snippets"
---

Save replies you use all the time and drop them into a draft by typing `/` or using the snippet button — shortcuts can fill in the recipient's name and email for you, and you manage them from Assistant settings.

- Talk instead of type in chat and compose — dictate into the editor, or start a live voice conversation with the assistant and insert or send the transcript when you're done
- Snooze with clear times of day like this afternoon, tomorrow morning, or next Monday, each showing when the message will return
- Meeting briefs lead with short priorities, decisions, and blockers, then useful attendee context
- Forwards show the files they're carrying, and those attachments go with the message on Gmail and Outlook
