---
description: "Custom MCP Servers"
---

Connect your own remote MCP server — like a knowledge base — from Integrations so draft replies can research against it alongside the built-in tools you already use.

- Add a server with OAuth or an API key, name it whatever you like, and remove it anytime
- Custom servers appear next to built-in integrations with a clear badge
- Available on Plus, with up to 10 custom servers per email account
