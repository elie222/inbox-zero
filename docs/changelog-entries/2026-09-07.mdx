---
description: "Label Conversations"
---

Apply Gmail labels without leaving Mail — hit L, pick an existing label or create one, and apply it to the conversation you're on or a bulk selection.

- Nested labels in the sidebar so paths like Inbox Zero/Archived nest cleanly under a parent
- Expand conversation previews to read more of the snippet before you open a thread
- Forward with F or Command K, and find more reader actions in the command palette
- Compose shortcuts for send, schedule, reminders, and attachments — plus theme switching from Command K
