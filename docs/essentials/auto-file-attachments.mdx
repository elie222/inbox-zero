## Set Up Auto-Filing

### Connect a Drive

Open **Attachments** under Tools in the left sidebar and choose **Add Google Drive** or **Add OneDrive**.

For Google Drive, choose an access level:

- **Standard**: You'll need to create new folders for filing.
- **Full access**: Use your existing folders.

### Pick Your Folders

Under **1. Pick your folders**, tick the folders in the folder tree that the assistant may file to. It only files to folders you select.

### Describe How You Organize

Under **2. Describe how you organize**, write one plain-English prompt that covers all your filing rules, including anything to skip. For example:

```text
Contracts go to Transactions by property address.
Receipts go to Receipts by month.
```

If your prompt calls for it, such as filing receipts by month or invoices by vendor, the assistant can create a new subfolder for a document when no existing folder fits.

### Review the Preview

Choose **Preview with my recent emails**. Under **3. See it in action**, the assistant files up to three recent attachments for real, without sending notifications, and shows where each one went. If a destination is wrong, select the ✕ under **Correct?** to move the file to the right folder. When you're happy, choose **Looks good, start auto-filing**.

## How Filing Works

When a new attachment arrives, the assistant files it in the matching folder. Documents that don't match your prompt are skipped. If it isn't sure where a file belongs, it emails you to ask for a destination instead of filing automatically.

The assistant owns the structure inside your allowed folders. When your filing rules imply a grouping (by vendor, client, project, year, or month), it creates the subfolders it needs, for example `Receipts/2026/Amazon`, and reuses them for later documents. Subfolders it creates are added to your allowed folders automatically. A new top-level folder is created only when none of your folders is a sensible parent.

## Corrections and Activity

Open **Attachments** to review **Recent Activity** and move a file to a different folder. You can also change your selected folders under **Allowed folders** and edit your prompt under **Filing rules**. Notification emails arrive in the source email thread, so you can also reply to approve a filing, move the file, or undo it. The assistant learns from these corrections.

## Delivery Settings

Use the **Delivery** button on the Attachments page to configure updates:

- **Email confirmations**: Receive an email when a file is sorted.
- **Connected apps**: Enable document-filing alerts for connected Slack, Microsoft Teams, or Telegram accounts. Configure or connect them on **Channels**.

For Slack, select a direct message or an allowed private channel. The selected Slack bot must already be invited to a private channel before it can post there.
